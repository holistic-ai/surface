# Tool logos

Each file is the tool's own mark (or, where the product publishes none, its
vendor's), fetched once from the URL below and composited onto a uniform
44px chip in Paper so the column in the README reads as one set and
stays legible in both GitHub themes. Every mark remains the trademark of its
owner and is used here only to identify the tool surface detects.

Regenerate with the script in the pull request that added them; refresh a
single logo by re-fetching its URL and re-running the same chip step.
